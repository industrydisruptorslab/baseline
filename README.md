## What is BASELINE?

An AI-native manufacturing decision intelligence platform powered by Gemini 
1.5 Pro, encoding 15 years and 50+ real MES implementations across European 
pharmaceutical, medical device, and industrial manufacturing plants.

### Two modules. One platform.

**PRE-MES** — For companies evaluating MES for the first time
- Structured requirements analysis (ISA-95 framework)
- Technical specifications definition
- MES platform evaluation & vendor scoring
- Business case generation

**POST-MES** — For companies with an existing MES that isn't working
- Problem diagnosis
- Root cause analysis (system / process / data / people)
- Prioritized action plan
- Implementation recovery roadmap

## How it works
User arrives → Chooses path (PRE-MES or POST-MES)

↓

↓
